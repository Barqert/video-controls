How to write shortcuts

    
These shortcuts use part of mpv’s input.conf format. The commands supported here are listed below.

    
# Lines starting with # are comments.
Alt+p cycle pause         # Pause or play
Alt+m cycle mute          # Sound on or off
Alt+n seek 5              # Skip forward 5 seconds
Alt+b seek -5             # Go back 5 seconds
Alt+] multiply speed 1.1  # Play 10% faster
Alt+r reset-all        # Reset the picture

    
Put ; between commands to run them with one key:

    
Alt+0 set speed 1; set video-zoom 0

    
Keys

    
Use letters, numbers, or symbols. Add Ctrl+, Alt+, or Shift+ to combine keys. Meta+ and Super+ also work for the Windows/Command key.

    
For example, Alt+LEFT means Alt and the left arrow. Alt++ means Alt and the plus key. Capital letters include Shift: A is Shift+A, while a is A without Shift.

    

      All key names and keyboard details
      
Arrow keys: LEFT RIGHT UP DOWN.

      
Other keys: SPACE ENTER ESC TAB BS BACKSPACE DEL INS HOME END PGUP PGDWN, and F1 through F24. ESCAPE also works for Escape.

      
Number pad: KP0 through KP9, plus KP_ADD KP_SUBTRACT KP_MULTIPLY KP_DIVIDE KP_ENTER KP_DEC.

      
You can write named keys like LEFT in lowercase too. Letter keys follow your keyboard layout. Symbols that need Shift use a standard US keyboard layout.

      
For compatibility with the old shortcuts, = also matches number-pad plus, and - matches number-pad minus, without Shift. Use the KP names to give number-pad keys their own shortcuts.

    

    
Commands

    
Replace PROPERTY with a setting such as speed or video-zoom. Parts in square brackets are optional; leave out the brackets when you type a command.

    

      
CommandWhat it does

      
        
set PROPERTY VALUESet a value. Example: set speed 1 returns to normal speed. Use yes or no for pause and mute.

        
add PROPERTY [AMOUNT]Add a number. Use a negative number to subtract. If you leave out the amount, it adds 1.

        
multiply PROPERTY FACTORMultiply a value. Example: multiply speed 2 doubles playback speed.

        
cycle PROPERTY [up|down]Switch pause or mute on and off. Either direction does the same thing.

        
cycle-values [!reverse] PROPERTY VALUE…Move through a list of values, then start again. Example: cycle-values speed 1 1.5 2. Add !reverse to go backward.

        
vf toggle hflip
vf toggle vflip		Flip the picture sideways or upside down. Replace toggle with add to turn the flip on, or remove to turn it off.

        
seek AMOUNT [FLAGS]Skip forward or backward by a number of seconds. Example: seek -10 goes back 10 seconds. More seek options are below.

        
ignoreMake a key do nothing. Use this in a fullscreen-only or outside-fullscreen box to turn off a Common shortcut in that mode.

      
    

    
Settings you can change

    

      
PropertyMeaning

      
        
video-pan-x
video-pan-y		Move sideways or up/down. A change of 0.1 moves the picture by 10% of its width or height.

        
video-zoomZoom in or out. 0 is normal size, 1 is twice as large, and −1 is half as large.

        
video-rotateRotate by a number of degrees. For example, 90 is a quarter turn.

        
speedPlayback speed. 1 is normal, 2 is twice as fast, and 0.5 is half speed.

        
volumeSound level from 0 to 100.

        
pause
mute		Use yes for on and no for off, or use cycle to switch between them.

      
    

    
Extra commands added by this extension

    
Multiply a value, then ease back

    
Alt+b multiply-decay speed 2 1

    
This doubles playback speed, then gradually brings it back to where it started. After one second, half of the extra speed is gone. After another second, half of what remains is gone.

    
The format is multiply-decay PROPERTY X Y:

    
    
      
  • X is the multiplier. Use 2 to double a value, or 0.5 to halve it.
    • 
      
  • Y controls how slowly it returns. It is the number of seconds for half the change to fade. A bigger number makes the effect last longer.
    • 
      
  • Both numbers must be greater than zero.
    • 
    

    
You can press the key again while the effect is running. The effects multiply together and each fades on its own. For example, two fresh 2× effects give 4×.

    

      Exact timing and what happens when you change a value
      
Y is called the half-life. After t seconds, each effect multiplies the value by 1 + (X − 1) × 2^(−t/Y). With X=2 and Y=1, that is 2× at first, 1.5× after one second, and 1.25× after two seconds.

      
Two 2× effects started together give 2.25× after one half-life. Each effect ends after 20 half-lives, so the value returns exactly to its starting value. The setting’s normal limits still apply.

      
add and multiply change the value the effect returns to. set and cycle-values cancel effects on that setting. Changing speed or volume using the site’s own controls also cancels effects on that setting.

      
Multiplying zero still gives zero. To use this on video-zoom, first set zoom to something other than zero.

      
Time keeps counting while playback is paused. A background tab catches up when the browser starts drawing it again.

    

    
Reset the picture

    
Alt+BACKSPACE reset-all

    
Undo moves, zoom, rotation, and flips. This also ends their temporary effects. Speed, sound, and pause stay as they are.

    
    

      More syntax: seeking, held keys, quotes, and limits
      
Seeking

      
seek 10 relative goes forward 10 seconds. seek 10 absolute jumps to 10 seconds from the start.

      
seek 10 relative-percent goes forward by 10% of the video’s length. seek 50 absolute-percent jumps to the middle. These need a video with a known length.

      
You can add +exact or +keyframes, for example seek 10 relative+exact. Keyframe seeking uses the browser’s fast seek feature when available, or regular seeking otherwise. The browser decides how precisely it can seek.

      
Holding a key

      
By default, add, multiply, and seek keep running while you hold the key. Other commands run once per press.

      
Put repeatable before a command to make it repeat, or nonrepeatable to stop it repeating. If a line has several commands, the first one decides whether the whole line repeats.

      
no-osd is accepted for mpv compatibility. It has no effect here because this extension does not show command messages over the video.

      
Quotes and comments

      
Blank lines are fine. A # starts a comment. You can put values inside single or double quotes. To include # or ; as part of a value, quote it or put a backslash before it. Outside single quotes, a backslash makes the next character part of the value.

      
Lists of values

      
If the current value is missing from a cycle-values list, the command starts at the first value. With !reverse, it starts at the last value.

      
Value limits

      
Pan: −100 to 100. Zoom: −10 to 10. Rotation: −360,000 to 360,000 degrees. Speed: 0.0625 to 16. Volume: 0 to 100. Values outside these ranges stop at the nearest limit. Your browser may allow a smaller range for speed or volume.

    

    

      Player compatibility
      
Normal HTML videos work, including videos inside open shadow roots (a way sites group parts of a page). Videos inside closed shadow roots, browser-internal pages, and separate picture-in-picture windows are not supported.
